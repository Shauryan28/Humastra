# HUMASTRA | Strategic Executive Search & Leadership Advisory

> **"HUMASTRA helps organizations make better leadership and talent decisions when the stakes are high."**

HUMASTRA is an executive search and strategic leadership advisory firm positioned as a **high-trust, high-touch advisory partner** for founders, CEOs, board nomination committees, and growth-stage investors. We advise enterprises on identifying, evaluating, and placing exceptional talent for mission-critical, board-level, and senior executive roles.

---

## Brand Positioning & Pillars

HUMASTRA is built on the philosophy of elite strategic advisory rather than transactional recruitment:

1. **Strategic Search:** Retained CXO and Board-level searches, specialized profiles, unannounced confidential replacements, and succession mandates.
2. **Leadership Advisory:** Organizational leadership team design, executive assessment, succession architectures, and founder-to-scale leadership transitions.
3. **Domain Intelligence:** Deep practice specialization across Technology & SaaS, Venture-Backed Scaleups, Consumer & D2C, Financial Services & FinTech, Precision Manufacturing, and Built Environment.
4. **Confidentiality Charter:** A four-point client protection protocol guaranteeing non-disclosure, anonymized talent mapping, encrypted communications, and strict non-solicitation covenants.

## Architectural & Technical Highlights

* **100% Semantic HTML5:** Clean document outline with proper landmark elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
* **Technical SEO First:**
  * Unique `<title>`, `<meta name="description">`, and canonical `<link>` on every page.
  * Exactly one semantic `<h1>` per page with a logical `<h2>`/`<h3>` hierarchy.
  * Comprehensive Schema.org JSON-LD structured data: `Organization`, `WebSite`, `Person`, `Article`, `BreadcrumbList`, and `ContactPage`.
  * Verified `sitemap.xml` and crawler-friendly `robots.txt`.
* **Zero Framework Bloat:** Ultra-performant Vanilla CSS custom property design system (`Newsreader` serif display + `Plus Jakarta Sans` grotesque sans-serif) and lightweight vanilla JavaScript.
* **Responsive & Accessible:** Fluid clamps (`clamp()`), mobile drawer navigation, WCAG AA contrast compliance, focus states, and skip-to-content links.
* **Interactive Features:** Accessible FAQ accordions, topic-filtered thought leadership engine, and an interactive mandate inquiry form with real-time validation and confirmation feedback.

## Local Development & Testing

Run the site locally with any static web server:

### Python
```bash
python -m http.server 8080
```
Open [http://localhost:8080/](http://localhost:8080/) in your browser.

### Node.js (npx serve)
```bash
npx serve .
```
